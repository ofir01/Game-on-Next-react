איך עובד קובץ yml:
כשאובייקט ההפעלה (docker compose) מריץ את הפקודה docker compose up --build, הוא מחפש באופן אוטומטי קובץ בשם docker-compose.yml בתיקייה שבה אתה נמצא.
ברגע שהוא מוצא אותו, הוא קורא את ההוראות שכתובות בו לפי הסדר הבא:
שלב הבנייה (build): הוא לוקח את ה-Dockerfile שלך, מעביר אליו אוטומטית את כל המשתנים שהגדרת תחת args (כדי שייצרבו בקוד של Next.js), ובונה את התמונה שנקראת game-on.
שלב יצירת הקונטיינר (image ו-ports): הוא לוקח את התמונה שנבנתה, יוצר ממנה קונטיינר חדש, ופותח את פורט 3000 במחשב שלך כך שיוביל לפורט 3000 בתוך הקונטיינר.
שלב ההזרקה (env_file): הוא פותח את קובץ ה-.env שלך ומזריק את כל שאר המפתחות (כמו מסד הנתונים של Neon וה-JWT) ישירות לסביבת הריצה של הקונטיינר.
ההבדל החשוב הוא ש-args מיועד לשלב הבנייה, ואילו env_file מעביר משתני סביבה לקונטיינר בזמן הריצה. הגדרת env_file לבדה אינה מעבירה את המשתנים לבנייה.
